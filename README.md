Digital Clock and Stopwatch Web Application-

A simple and interactive web application built using HTML, CSS, and JavaScript that displays a real-time digital clock and a functional stopwatch.

✨Features✨-

Real-time Digital Clock Stopwatch with Start, Stop, and Reset functions Stylish bordered clock and stopwatch display Simple and responsive user interface Easy-to-understand JavaScript logic

✨Technologies Used✨-

HTML CSS JavaScript

✨How It Works✨-

#Digital Clock-

Uses JavaScript Date() object to get the current time. Updates every second using setInterval(). Displays hours, minutes, and seconds in real-time.

#Stopwatch-

Start button begins counting time. Stop button pauses the stopwatch. Reset button resets the timer to 00:00:00. Time is updated every second dynamically.
